Google's Approach

Google uses a combination of:

  • margin: 0 auto - to center the search container
  • text-align: center - to center inline elements
  • position: absolute - for some elements

What we need to implement:

  1. margin-left, margin-right, margin-top, margin-bottom properties
  2. CSS "auto" value for margins
  3. justify-content and align-items for flexbox
  4. position: absolute/relative/fixed (Phase 7 goal)
